# 推理计数与返回状态排查（2026-10-16）

用户复现发生在普通聊天：算力任务卡已经出现答案，但仍显示推理中，聊天端未返回。性能对比通过停用一台算力设备进行。

## 可复现的代码缺陷与修复

- 页面此前在忙时暂停全部负载同步，远端 `modelRequests` 可停在旧值；收到仅含路数的响应时又未识别为状态。现改为开始/结束立即推送模型名与本机生成路数，忙时每两秒刷新；转发任务不计入本机生成，间接设备卡片使用其上报路数。
- `LocalChat` 此前收到完整 `stream:false` 回答只推送文本，等待原生 `end`（位于 Session 销毁之后）才发送完成。现将完整回答交付与原生清理解耦；已交付的请求不再算生成中，缓存仍等清理完成才解除占用，清理失败不撤回已交付答案。
- `InferenceHost` 的任务卡回调与协议交付隔离，避免界面回调异常令收到文本的请求丢失终态。

这些是代码及离线回归能够证明的缺陷；尚不能断言它们覆盖此次真机现象的全部原因。
